# Architectural decision records

- Document type: **decision**
- Status: **current**
- Applies to: architectural decision records
- Last reviewed: 2026-10-20

Use this directory for decisions whose rationale must remain independently
reviewable after implementation plans are archived. Name records
`NNNN-short-title.md` and include context, decision, consequences, status and any
superseding record.

Accepted records are immutable except for status and supersession links. A new
decision supersedes an old record instead of rewriting its historical rationale.
No standalone ADR has been accepted on the current rebuild baseline yet.
